Perintah tersebut menjalankan “pekerja latar belakang” Laravel:

```bash
php artisan queue:work --queue=operations,default --tries=2 --timeout=900
```

Fungsinya:

- mengambil pekerjaan dari tabel `jobs`;
- menjalankan sinkronisasi ARKAS tanpa membuat browser menunggu;
- memperbarui status `QUEUED → RUNNING → COMPLETED/FAILED`;
- memproses queue `operations` lebih dahulu, kemudian `default`;
- mencoba ulang pekerjaan maksimal 2 kali;
- memberi batas maksimal 900 detik atau 15 menit per pekerjaan.

Ya, worker harus aktif selama aplikasi digunakan. Setelah Windows atau server restart, proses worker berhenti dan perlu dijalankan kembali. Jika worker tidak aktif, aplikasi tetap dapat dibuka, tetapi sinkronisasi akan terus berstatus `QUEUED` dan tidak diproses.

Untuk lingkungan pengembangan, jalankan terminal terpisah:

```bash
php artisan queue:work --queue=operations,default --tries=2 --timeout=900
```

Biarkan terminal tersebut tetap terbuka.

Untuk penggunaan produksi di Windows, sebaiknya dijadikan proses otomatis menggunakan salah satu pilihan:

- Windows Task Scheduler dengan trigger “At startup”; atau
- Windows Service menggunakan NSSM/WinSW.

Konfigurasi yang disarankan:

- program: lokasi `php.exe`;
- working directory: `D:\lrvProject\spj-bosp-web`;
- arguments:

```text
artisan queue:work --queue=operations,default --tries=2 --timeout=900 --sleep=2
```

Dengan cara ini worker otomatis hidup kembali setelah komputer restart tanpa perlu menjalankan perintah manual. Worker yang saya jalankan sebelumnya hanya berlaku untuk sesi Windows saat ini.
